# Experiment 21 — Candidate Recall (Phase 4, Experiment I — THE GATE)

## Hypothesis

Хаотический mixer способен дешёво сформировать множество потенциально
релевантных кандидатов для каждого query-токена — кандидаты, которые
совпадают с тем, что full attention считает важным.

## Setup

- Учитель: AttnLM (exp13 checkpoint, single-head full attention, W=256,
  BPE-512, обучен на коде 12K шагов).
- Mixer: Hierarchical Chaotic Mixer (exp14 checkpoint mixer_1.pt, обучен).
- 1500 тестовых окон (stride 32), query = последняя позиция.
- Скоринги кандидатов против Top-K_attention учителя:
  - chaos_qk:  h_query · h_candidate (смешанные хаотические состояния)
  - raw_qk:    h_raw_query · h_raw_candidate (НЕсмешанные — контроль)
  - linear:    обученный линейный зонд на смешанных состояниях (контент-независимый)
- Метрики: recall, precision (=recall для top-K), jaccard, top1_hit, any_hit,
  среднее расстояние кандидатов. K = 4..64.
- Корреляции Spearman/Pearson chaos_qk vs attention (Exp VII).

## Results

| K | chaos_qk recall | raw_qk recall | linear recall | random K/W |
|---|---|---|---|---|
| 4 | 0.076 | 0.040 | 0.154 | 0.016 |
| 8 | 0.098 | 0.053 | 0.182 | 0.031 |
| **16** | **0.118** | 0.079 | 0.219 | 0.063 |
| 32 | 0.167 | 0.142 | 0.286 | 0.125 |
| 64 | 0.277 | 0.261 | 0.388 | 0.250 |

Корреляция: Spearman = 0.044, Pearson = 0.062. chaos top-1 == attn top-1: 0.013.
Среднее расстояние кандидатов от запроса: chaos 69-122, linear 24-80.

## Interpretation

1. **Recall@16 = 11.8%** — гейт (50%) провален в 4 раза. Хаотические кандидаты
   почти не совпадают с attention-релевантными связями (лишь 1.9× выше случайных).
2. **Корреляция хаос↔attention ≈ 0** — хаотические состояния не кодируют
   то, что attention считает важным. Контент-зависимая релевантность не
   возникает из контент-независимой динамики (математический факт: пермутация
   + фиксированное сцепление не зависят от содержания запроса).
3. **Mixer даёт небольшую организацию**: chaos_qk > raw_qk (0.118 vs 0.079) —
   но это не та организация, что нужна для маршрутизации.
4. **Линейный зонд > chaos_qk** (0.219 vs 0.118) и его кандидаты БЛИЗКО к
   запросу (24-80 vs 69-122). Attention учителя локальна; глобальное
   хаотическое перемешивание разрушает локальную структуру.
5. exp19 (Sparse Attention с top-K) подтверждает: sparse на хаотических
   кандидатах ≈ full attention минус ~2% PPL — потому что бОльшая часть
   полезной информации локальна/широковещательна, а не из-за качества routing.

## Conclusion

**Опровергнуто (Level 0 по критериям Phase 4).** Хаотическая динамика НЕ
предсказывает attention-релевантные связи (Recall@16 = 11.8%, корреляция ≈ 0).
Гипотеза sparse routing через хаос в текущей формулировке не подтверждена.

**PATH A**: не спасать идею косметическими изменениями. Хаотический mixer
остаётся дешёвым пропозером-перемешивателем (broadcast), но НЕ является
routing/proposal-механизмом для attention.
