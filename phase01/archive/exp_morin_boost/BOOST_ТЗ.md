# ТЗ: BOOST MORIN-FILTER — «Память доверия» (Trust-Prior)

## Контекст (измеренный, не гипотетический)

Morin-filter = Jelinek-Mercer (β-смесь) + n-граммная таблица. Честные ограничения:

| Проблема | Измерение | Источник |
|---|---|---|
| β глобальный (0.3) | адаптивный β=tot/(tot+kb) даёт **+58%** | exp09 |
| Точный lookup разрежён | order-8: q_miss=0.82, order-16: 0.76 | exp_memory_selector |
| Найденный паттерн почти всегда верен | t_miss=0.014 (1.4%!) | exp_memory_selector |

**Ключевой факт:** когда lookup находит паттерн — точность 98.6%. Проблема только в
ПОКРЫТИИ. Значит прорыв = поднять покрытие, сохранив точность.

## Гипотеза прорыва

**Trust-Prior**: распределение доверия (trust) по КОНТЕКСТАМ, а не по токенам.
Модель учится, КАКИМ контекстам доверять (β высокий), каким нет (β низкий), и
КАК склеивать порядки (order-1..8 → взвешенная интерполяция вместо backoff).

```
log P_mix = logaddexp(log(1-β(ctx)) + log P_model, log β(ctx) + log P_prior(ctx))
β(ctx) = σ(обучаемая сеть над признаками контекста)   ← НОВОЕ
P_prior(ctx) = Σ_L w_L(ctx) · P_orderL(ctx)            ← НОВОЕ (вместо backoff)
```

## Эксперименты (все CPU)

| ID | Что | Контроль |
|---|---|---|
| T0 | Baseline: morin как есть (order-2, β=0.3) | README цифры (9.0 / 4.0) |
| T1 | Адаптивный β = tot/(tot+kb) | T0 |
| T2 | Trust-Prior: обучаемая интерполяция порядков (logreg на признаках) | T1 |
| T3 | Neural Trust: β(ctx) из признаков (маленькая сеть, CPU) | T2 |

## Признаки контекста для сети (дёшево, O(1))

- tot_L = суммарная частота контекста длины L (для L=1..8)
- hit_L = найдена ли таблица порядка L
- энтропия распределения order-3
- длина контекста, позиция в тексте
- (после T2) оценочная уверенность: max-вероятность prior

## Предрегистрированные вердикты

- **V1 (T1 vs T0):** адаптивный β улучшает PPL ≥10% на том же корпусе
  → подтверждает exp09 на morin-протоколе. Иначе — баг протокола.
- **V2 (T2 vs T1):** обучаемая интерполяция порядков улучшает ≥5%
  → покрытие растёт без потери точности (гипотеза прорыва частично).
- **V3 (T3 vs T2):** Neural Trust (β от признаков) улучшает ≥5%
  → прорыв: morin становится ОБУЧАЕМЫМ, масштабируется с данными.

## Stop-rule

Если T1 не бьёт T0 (β адаптивный не помогает) → протокол/стенд багнут, чинить стенд.
Если T2 не бьёт T1 → покрытие не лечится интерполяцией, перейти к Neural Trust сразу.
Если T3 не бьёт T2 → буст исчерпан честно: morin оптимален в своей форме, закрыть с
отрицательным результатом + остаётся опция «обучаемый prior вместо lookup» (другое ТЗ).

## Метрики (все честные)

- PPL на test (4:1 split, как в morin-протоколе)
- top-1 accuracy
- покрытие (доля контекстов с наблюдением)
- recall@10 (мишень в top-10 prior)
- эффективные кандидаты (экс-энтропия смеси)
