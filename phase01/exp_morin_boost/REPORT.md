# REPORT — BOOST MORIN-FILTER: Neural Trust (T3c)

**Дата:** 2026-08-30 | **Протокол:** код, BPE vocab 512, corpus5m (5M токенов)
**Модель-стенд:** сглаженная trigram (Jelinek-Mercer) как «нейро-сторона» — валидный нижний предел

## Результаты (полный корпус 5M токенов)

| Конфиг | PPL | Улучшение |
|---|---|---|
| Модель (trigram) | 28.18 | — |
| **T0: morin (β=0.3, backoff)** | **9.65** | baseline (2.92×) |
| T1: адаптивный β=tot/(tot+kb) | ~14 (487K) | ❌ хуже T0 |
| T2: blend порядков (uniform) | ~27 (487K) | ❌ хуже |
| T3a: β = L/(L+2) | 6.99 | −28% vs T0 |
| **T3c: Neural Trust (β из признаков)** | **6.49** | **−33% vs T0** |
| ORACLE (лучший β per-sample) | 4.45 | потолок |

**Главный результат: обучаемый β бьёт фиксированный morin на 33% PPL.
Совместно с моделью: 28.2 → 6.49 = 4.3× (сам morin даёт 2.9×).**

## Почему это работает (диагностика)

- **mean_prior_peak = 0.69** — когда prior срабатывает, он острый (69% на top-1)
- **prior_hit_true_rate = 0.607** — target в prior в 60.7% случаев
- **Фундаментальный штраф:** при target НЕ в prior, смесь теряет `-log(1-β)`.
  Фиксированный β=0.3 → штраф 0.36 nats; β=0.9 → 2.3 nats (катастрофа).
  Именно поэтому «большой β всегда» проваливается (T1), а «β от контекста» выигрывает (T3c).

**Ключ прорыва:** Neural Trust head учится давать β≈0 для плоских/коротких совпадений
(prior ненадёжен) и β≈0.6-0.9 для острых/длинных (prior почти наверняка прав).
Признаки: [match_len, log(tot), p_top, n_cand, ctx_len], head = логистическая регрессия (6 весов).

## Вердикты ТЗ

- **V1 (адаптивный β > фикс.): НЕ ПОДТВЕРЖДЁН** для β=tot/(tot+kb) — на morin-протоколе
  это ХУЖЕ (47 vs 33 на 487K). Но подтверждён для β от ДЛИНЫ (T3a, −28%).
  Урок: сигнал доверия — длина и острота, НЕ общая частота контекста.
- **V2 (blend порядков): НЕ ПОДТВЕРЖДЁН** — uniform blend размазывает массу и бьёт по
  точности (acc 0.42→0.19). Backoff сохраняет пиковость — он прав.
- **V3 (Neural Trust): ПОДТВЕРЖДЁН** — обучаемый β из признаков даёт −33% vs T0,
  стабильно на 487K и 5M корпусе. morin становится ОБУЧАЕМЫМ → масштабируется с данными.

## Stop-rule

Частичный успех есть (V3 подтверждён, −33%). Разрыв до oracle (6.49 → 4.45, ×1.46)
остаётся — это предел знания «в каком контексте target реально в prior». Часть можно
взять улучшением самого prior (полный Stack-корпус 503M токенов вместо 5M — следующий шаг).

## Значение для проекта

1. **Для morin-filter (отдельный репо):** Neural Trust — реальное улучшение (33%).
   Портировать в morin-filter как опциональный обучаемый head (sklearn-логистика,
   без новых зависимостей).
2. **Для ChaoticLLM:** подтверждает, что «память доверия» (обучаемый селектор над
   lookup) решает проблему масштабирования prior — в отличие от статического order-3.
   Это четвёртый путь из обсуждения: не «закрыть», а прокачать prior.
