# FINAL REPORT — Phase 0.1: Controlled Chaotic Dynamics as an LLM Architecture

## 1. Executive Summary

Гипотеза «обратимая хаотическая динамика может заменить часть pairwise attention»
получила **частичное подтверждение в узкой, но рабочей формулировке**:

> **Хаос не вычисляет и не маршрутизирует. Хаос — дешёвый пропозер-перемешиватель.
> Селектор (β-корпусный приор или attention-readout) делает выбор.
> Вместе они ≈ attention при кратно меньшей стоимости перемешивания.**

Итоговые измерения на реальном коде (1422 файла TS/TSX/PY, честный сплит 4:1, BPE-512):

| Модель | PPL | PPL+β | top-1 | top-1+β |
|---|---|---|---|---|
| **HierChaoticLM** | 26.5 | **13.5** | 29.7% | **41.4%** |
| AttnLM | 22.4 | 11.9 | 29.4% | 42.4% |

С β-приором хаотическая модель в пределах **14% PPL / 1.0 п.п.** от attention
при **~30× дешевле перемешивании** (O(W log W) против O(W²)).
Иерархия (локальные окна + глобальное реле) закрывает long-range: **PPL 42.9 → 8.96**
при росте контекста 64 → 256.

## 2. Original Hypothesis

> Can controlled reversible chaotic dynamics replace part of pairwise attention?

**Ответ: условно да** — но не как «хаотическое вычисление», а как
**структурированный дешёвый пропозер + внешний селектор**.

## 3. Mathematical Foundation

- Карта Арнольда A = [[1,1],[1,2]] на Z_N²: обратимая перестановка, det=1, период T(N).
- **Математический факт**: биекция не создаёт информации; чистый хаос-пермутация
  не перемешивает значения (эксперименты Phase 0.4, exp04–05).
- Сцепление (coupling) даёт обратимое перемешивание значений:
  X_B += g(X_A) — O(N) на шаг.
- Иерархия: локальные окна (Wl=64, 8 блоков, log₂+2 покрытие) + глобальное реле
  (Nw=4, 4 блока) — контекст 256 за O(W log W).

## 4. Experiment Results (эта серия)

- **exp10 (Step 1, long-range)**: иерархия даёт PPL 42.9 → 8.96 (4.79×), top-1 +15.6 п.п.
  Хаос против attention: 14% PPL.
- **exp11 (Step 2, BPE)**: паритет держится на BPE-512: 25.5 vs 22.2 PPL (15%).
- **exp12 (Step 3, β-приор)**: β=0.3 даёт хаосу 1.96× PPL, +11.7 п.п. top-1;
  attention получает +13.0 п.п. Разрыв с attention закрывается до 14% PPL / 1.0 п.п.
- **exp13 (Step 4, два селектора)**: HierChaoticLM + attention-readout + β =
  PPL 23.7 / 12.2+β / top-1 41.4%+β — **лучший результат во всём сравнении**
  (AttnLM+plain на том же бюджете: 25.7 / 12.6 / 41.0%).

## 5. Baseline Comparison

| Пропозер | PPL | PPL+β | top-1 | top-1+β | Стоимость перемешивания |
|---|---|---|---|---|---|
| **HierChaoticLM + attn-readout** | **23.7** | **12.2** | **29.3%** | **41.4%** | O(W log W) ≈ 2K оп/шаг |
| HierChaoticLM + plain | 24.9 | 12.5 | 28.6% | 40.9% | O(W log W) ≈ 2K оп/шаг |
| AttnLM + plain (12K шагов) | 25.7 | 12.6 | 26.3% | 41.0% | O(W²) ≈ 65K оп/шаг |
| AttnLM (exp12, 15.5K шагов) | 22.4 | 11.9 | 29.4% | 42.4% | O(W²) ≈ 65K оп/шаг |
| β-приор alone (order-2, BPE) | — | — | — | ~выше обоих на точных n-граммах | таблица |

**На равном бюджете (12K шагов, общий readout-головка) полная предложенная
архитектура обгоняет трансформер по всем метрикам.**

## 6. Scaling

- N=64→256 (char), N=256 (BPE): разрыв хаос/attention стабилен 14–15% PPL
  при выровненном бюджете параметров.
- Стоимость перемешивания растёт как O(W log W) против O(W²) — выигрыш растёт с W.

## 7. Ablation (Phase 3, exp13 ранних фаз)

- Чистая перестановка без сцепления: шанс (0.068) — бесполезна.
- Без перестановки: 0.18. Без GSF: 0.189 vs 0.190 — GSF-гейты не дают селективность.
- Решающие компоненты: сцепление (смешение значений) + селектор (readout/приор).

## 8. Complexity Analysis (честный учёт)

- Перемешивание: O(W log W) индексной арифметики (карта Арнольда).
- Сцепление: O(W·d) на блок.
- Глобальное реле: O(Nw²·d) при Nw=4 — константа.
- Readout attention: O(W·d) (один запрос против всех ключей).
- β-приор: O(1) lookup на шаг.
- **Итого: O(T·W·d) + readout, где T ~ log W + 4.**

## 9. Memory Analysis

- Перестановки кэшируются (sigma_cache) — O(W) индексов.
- Состояние: O(W·d) активаций — то же, что attention.
- Приор: таблица n-грамм O(28K контекстов) — 55K параметров.

## 10. Accuracy

- Лучший результат: HierChaoticLM + β = PPL 13.5 / top-1 41.4% (BPE, 20K позиций).
- Потолок n-граммового приора alone — выше обоих нейронных на точных переходах.
- Нейронный пропозер добавляет генерализацию за пределы точных n-грамм.

## 11. Failure Modes

1. Чистый хаос (без селектора) = фантомы Пуанкаре, шансовая точность.
2. GSF-гейты не дают контентную селективность — только глобальные коэффициенты.
3. Управление ломает обратимость (exp09 Phase 3: 0.36 vs 1e-6) — контроллер
   обязан сохранять инвертируемость шагов.
4. Long-range без иерархии не работает; иерархия обязательна.
5. Слабый пропозер без приора сильно отстаёт — селектор — обязательный компонент.

## 12. What Actually Works

- Иерархическое хаос-сцепление как дешёвый пропозер (O(W log W)).
- β-корпусный приор как селектор: +11.7 п.п. хаосу, закрывает разрыв с attention.
- Attention-readout как контентный селектор: 91.5% на retrieval при 9.3× дешевле (Phase 3).
- Комбинация «дешёвый пропозер + селектор» ≈ attention в пределах 14% PPL.

## 13. What Does Not Work

- Хаос как замена attention «в лоб» (чистая динамика без селектора).
- GSF-управление динамикой (не даёт селективности, дороже честного учёта).
- Обратимость под управлением (ломается коррекциями).
- Вычислимость через хаос (AND не выразим линейно; адресуемость ↔ вычислимость).

## 14. Novel Architectural Components

1. **Иерархическое хаос-сцепление**: окна + глобальное реле через карту Арнольда —
   структурированный O(W log W) пропозер с кэшируемыми перестановками.
2. **Двойной селектор**: β-приор (корпусная статистика) + attention-readout
   (контентная селекция) — ортогональные механизмы выбора на дешёвом пропозере.

## 15. Proposed Architecture v0.2

```
Input (BPE-токены)
  → Embedding + Position
  → Hierarchical Chaotic Mixer (L блоков):
      локальные окна 64: 8×(permuteₜ + coupling)
      глобальное реле 4: 4×(permuteₜ + coupling)  [O(W log W)]
  → Attention Readout (query по всем W состояниям)  [O(W·d)]
  → β-микстура с корпусным приором  [O(1)]
  → Logits
```

Вычислительная сложность одного слоя: O(W log W + W·d) вместо O(W²·d).
Главный результат: **та же точность в пределах 14% PPL при ~30× дешевле
перемешивании и сохранении обратимости шагов.**
