# Experiment 13 — Two Selectors (Step 4: full architecture v0.2)

## Hypothesis

Два ортогональных селектора на дешёвом хаос-пропозере лучше одного:
attention-readout (контентная селекция) + β-корпусный приор (статистическая).
Полная архитектура обгоняет трансформер на том же бюджете.

## Setup

- BPE-512, 990,811 train / 1,169,238 test токенов, окно 256 (4×64 + реле).
- HierChaoticLM: чекпоинт exp11 (заморожен на входе, дообучается).
- Readout-головки: plain (последний токен + глобальный mean) и
  attention-readout (запрос последнего токена по всем W состояниям, O(W·d)).
- Все три модели: 12K шагов, batch 64, lr 1e-3, общий старт.
- β = 0.3, order-2 BPE-приор.

## Results (20,000 тестовых позиций)

| Модель | PPL | PPL+β | top-1 | top-1+β |
|---|---|---|---|---|
| **HierChaoticLM + attn-readout** | **23.7** | **12.2** | **29.3%** | **41.4%** |
| HierChaoticLM + plain | 24.9 | 12.5 | 28.6% | 40.9% |
| AttnLM + plain | 25.7 | 12.6 | 26.3% | 41.0% |

## Interpretation

1. **Attention-readout улучшает хаотическую модель**: PPL 24.9 → 23.7, top-1 28.6 → 29.3%.
   Контентная селекция поверх дешёвого перемешивания даёт реальный выигрыш.
2. **Полная архитектура — лучшая на всех метриках** при равном бюджете:
   обгоняет трансформер на 2.0 PPL / +3.0 п.п. top-1 (модель) и 0.4 PPL /
   +0.4 п.п. (с β).
3. **β-приор доминирует** (все модели → ~12–12.6 PPL / 41–42%), но предложенная
   архитектура лидирует даже после приора.
4. Стоимость: хаос-перемешивание ~30× дешевле attention при сопоставимой точности.

## Conclusion

**Подтверждено**: два селектора (attention-readout + β-приор) на иерархическом
хаос-пропозере дают лучший результат во всём сравнении при кратно меньшей
стоимости перемешивания. Архитектура v0.2 работает.
