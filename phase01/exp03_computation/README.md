# Experiment 03 — Chaos as Computational Layer

## Hypothesis

Может ли траектория динамической системы сама выполнять вычисление (XOR, parity, классификация, ассоциативный поиск) дешевле baseline?

## Mathematical model

(a) Автономная карта + readout: y = readout(Aᵀ·x₀). Aᵀ — фиксированная ЛИНЕЙНАЯ карта. Она **поглощаема**: readout(Aᵀ·x₀) = (readout∘Aᵀ)(x₀) — тот же по ёмкости классификатор. Карта не добавляет вычислительной способности.

(b) Управляемая динамика: x_{t+1} = A·x_t + u(x_t, θ) — нелинейная рекуррентная карта = **RNN**.

## Results

| Задача | MLP на сыром x₀ | MLP на A⁵(x₀) | Δ |
|---|---|---|---|
| xor | 0.510 | 0.520 | -0.010 |
| and | 0.748 | 0.748 | 0.000 |
| parity8 | 0.557 | 0.564 | -0.007 |
| assoc | 0.861 | **0.615** | **+0.246** |

## Interpretation

1. **Поглощаемость подтверждена измерениями**: accuracy на сыром x₀ и на A⁵(x₀) одинакова (Δ≈0) для and и parity8 — карта не добавляет ёмкости.
2. **Хаотическая карта ВРЕДИТ на ассоциативном поиске**: 0.86 → 0.62 — она перемешивает структуру (key,value), которую readout должен читать.
3. Управляемая версия = RNN (не ново); её стоимость = стоимость RNN.

## Conclusion

**Опровергнуто (вычисление)**: фиксированная хаотическая карта не даёт вычислительной силы (поглощаема, на ассоциативных задачах вредна). Управляемая динамика сводится к RNN.
