# Experiment 12 — Full Architecture + Beta-Prior (Step 3)

## Hypothesis

Полная предложенная архитектура v0.2 (HierChaoticLM + β-корпусный приор)
закрывает разрыв до attention и работает на BPE-уровне.

## Setup

- BPE-512 (tokenizers), 990,811 train / 1,169,238 test токенов, окно 256.
- HierChaoticLM: 4 локальных окна 64 (8 блоков) + глобальное реле (4 блока).
  Чекпоинт exp11 (15,5K шагов) переиспользован.
- β-приор: order-2 BPE n-граммы из train, 28,176 контекстов, β=0.3.
- AttnLM: 1 слой full attention, окно 256, обучен 15,5K шагов.

## Results

| Модель | PPL | PPL+β | top-1 | top-1+β |
|---|---|---|---|---|
| **HierChaoticLM** | 26.5 | **13.5 (1.96×)** | 29.7% | **41.4% (+11.7 п.п.)** |
| AttnLM | 22.4 | 11.9 (1.89×) | 29.4% | 42.4% (+13.0 п.п.) |

## Interpretation

1. β-приор даёт хаотической модели почти двукратный выигрыш по PPL
   (26.5 → 13.5) и +11.7 п.п. top-1.
2. Разрыв с attention после приора: 14% PPL / 1.0 п.п. (было 18% без приора).
3. Эффект приора одинаков на обоих пропозерах (+11.7 vs +13.0) — хаос
   не хуже attention пользуется селектором.
4. При этом перемешивание хаоса ~30× дешевле (O(W log W) vs O(W²)).

## Conclusion

**Подтверждено**: полная архитектура с β-приором ≈ attention в пределах
14% PPL при ~30× дешевле перемешивании. Синтез «дешёвый пропозер + селектор»
работает на BPE-уровне.
