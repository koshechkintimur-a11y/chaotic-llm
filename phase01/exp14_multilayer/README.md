# Experiment 14 — Multi-Layer Chaotic Mixer (Step 5a)

## Hypothesis

Углубление (L=1, 2, 4 слоя иерархического хаос-миксера) даёт кумулятивный
выигрыш, как у трансформеров.

## Setup

- BPE-512, 990,811 train / 1,169,238 test, окно 256 (4×64 + реле).
- Каждый слой: локальные окна (8 блоков) + глобальное реле (4 блока),
  residual + LayerNorm.
- L = 1, 2, 4 слоя; 6000 шагов, batch 64, lr 1e-3, общий старт.
- Readout: attention-readout + β-prior (0.3).

## Results (20,000 тестовых позиций)

| Глубина | Параметры | loss @4K | PPL модель | PPL +β | top-1 модель | top-1 +β |
|---|---|---|---|---|---|---|
| **L1** | 99,340 | 3.48 | **32.5** | **13.7** | **23.3%** | **40.6%** |
| L2 | 99,352 | 3.22 | 33.6 | 13.8 | 23.2% | 40.6% |
| L4 | 99,376 | 4.08 | 41.8 | 14.8 | 19.4% | 40.3% |

## Interpretation

1. **Глубина не даёт выигрыша — она вредит.** L1 < L2 < L4 по PPL (32.5 → 33.6 → 41.8).
2. **Причина в архитектуре**: каждый хаос-блок содержит только гейт-скаляры
   (~12 параметров). L1/L2/L4 ≈ 99.3K параметров — углубление НЕ добавляет ёмкости.
   В трансформере каждый слой имеет QKV+FFN (полная ёмкость); здесь слой —
   фиксированное перемешивание + сцепление, не обучаемое представление.
3. L2 на тренировке даёт loss 3.22 (ниже L1 3.48) но не переносится на тест —
   нет ёмкости для обобщения; L4 переобучается на хаос-шум (loss 4.08).
4. β-приор частично сглаживает (13.7 → 14.8), но не компенсирует.

## Conclusion

**Опровергнуто**: многослойность в текущем виде не даёт кумулятивного выигрыша.
Чтобы глубина работала, хаос-блоки должны нести собственные обучаемые проекции
(пер-слойные линейные отображения) — это следующий шаг дизайна.
