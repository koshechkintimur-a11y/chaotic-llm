# Experiment 10 — Hierarchical ChaoticLM (Step 1: close long-range)

## Hypothesis

Одиночное хаотическое окно не тянет long-range (exp05). Иерархия: локальные окна 64 + глобальное хаотическое реле над их представлениями — должна вернуть использование дальнего контекста. Контекст 256 = 4 окна по 64 + реле над 4-токенными представлениями (2×2 grid).

## Setup

- Корпус: код пользователя (сплит 4:1 по файлам), 1.5M символов train, char-level (vocab 160).
- HierChaoticLM: 4× локальных окна (8 хаос-блоков на 8×8) + глобальное реле (4 блока на 2×2). 45.3K параметров.
- AttnLM: 1 слой attention на окне 256. 58.0K параметров.
- Одинаковый бюджет обучения (1 эпоха, batch 128).
- Проба long-range: PPL с контекстом 64 (только локально) vs 256 (иерархия).

## Results (30,000 тестовых позиций)

| Модель | Контекст | PPL | top-1 |
|---|---|---|---|
| HierChaoticLM | 64 (локально) | 42.9 | 29.4% |
| **HierChaoticLM** | **256 (иерархия)** | **8.96** | **45.0%** |
| AttnLM | 256 | 7.85 | 48.3% |

**Long-range gain (иерархия vs локально): PPL 42.9 → 8.96 = 4.79×, top-1 +15.6 п.п.**

## Interpretation

1. **Иерархия закрывает дыру long-range**: глобальное реле даёт хаосу доступ к дальнему контексту (4.79× PPL). Модель РЕАЛЬНО использует контекст 256.
2. **Хаос ≈ attention при контексте 256**: PPL 8.96 vs 7.85 (разрыв 14%), top-1 45.0 vs 48.3 (3.3 п.п.) — при 22% меньших параметрах и ~30× дешевле смешивании (2K vs 65K оп/шаг: 4·64·8 локально + 4·4 глобально vs 256²).
3. Одиночное окно 64 (локально) — слабо (PPL 42.9); иерархия обязательна для long-range.

## Conclusion

**Подтверждено**: иерархическое хаотическое перемешивание (локальные окна + глобальное реле) возвращает long-range и приближается к attention при существенно меньшей стоимости. Это снимает главное ограничение exp05.
