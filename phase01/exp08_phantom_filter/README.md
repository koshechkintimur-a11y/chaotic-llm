# Experiment 08 — Phantom Filter: The Missing Parameter

## Hypothesis (синтез user: morin-filter + chaos)

Morin-filter показал: ~90% локально правдоподобных переходов — фантомы, и победитель — β-микстура с корпусным приором. В хаосе: орбита — цикл Пуанкаре (локально валиден, глобально пуст). Недостающий параметр в уравнении — β (смесь хаоса и приора).

## Results

### A. Phantom rate хаотического пропозера
- 8 целей (шары r=3, ~9.6% пространства), орбита 48 шагов
- **Phantom rate = 3.2%** — 96.8% траекторий хотя бы раз задевают какую-то цель. Но это НЕ значит, что они попадают в ЦЕЛЕВУЮ (правильную) цель — лишь в какую-то.

### B. Accuracy vs β (хаотический пропозер + корпусный приор)
| β | Accuracy | Кто работает |
|---|---|---|
| 0.0 | 0.274 | Чистый хаос — чуть выше шанса (0.125) |
| 0.1 | 0.489 | Приор добавляет информацию |
| 0.3 | 0.643 | Микстура — хаос + приор |
| 0.5 | 0.798 | Приор доминирует |
| **0.7** | **1.000** | Почти чистый приор |
| 1.0 | 1.000 | Чистый приор |

### C. Случайный пропозер + тот же приор
| β | Accuracy |
|---|---|
| 0.0 | 0.121 (шанс) |
| 0.3 | 0.583 |
| 1.0 | 1.000 |

## Interpretation

1. **β — недостающий параметр в уравнении.** Без него (β=0) хаос — фантомный генератор с accuracy 0.274 (против 0.125 шанса). С ним (β≥0.3) система работает (0.64–1.00).
2. **Хаос не полностью заменяем случайным пропозером** (0.274 vs 0.121 на чистом хаосе) — детерминированная структура (encoding + орбита) даёт слабый сигнал. Но приор всё равно делает основную работу (β=0.3: 0.643 vs 0.583 — разница ~6%).
3. **Цикл Пуанкаре = фантомный цикл Морина.** Траектория возвращается в начало — замкнутый цикл, валидный в динамике, пустой как вычисление. Приор фильтрует фантомов.

## Conclusion

Недостающий параметр найден: **β — вес микстуры хаотического пропозера с корпусным/выученным приором**. Уравнение: x_{t+1} = (1−β)·F_chaos(x_t) + β·G_prior(x_t, context). Приор делает работу, хаос — дешёвый пропозер. Это объясняет и Phase 3 (0.92: хаос + attention-readout = пропозер + приор), и ограничение Phase 0.1 (чистый хаос ≈ фантом).
