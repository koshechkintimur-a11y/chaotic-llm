# Experiment 18 — Removing Attention-Readout (Step 6)

## Hypothesis

Attention-readout можно заменить селектором, использующим динамику самого
пространства. Два варианта:
- V1: локальный readout (последний токен + глобальный mean) — «просто убрать attn»
- V2: якорный запрос — запрос впрыскивается обратно в динамику, контекст
  смешивается «вокруг» якоря — «селекция через динамику пространства».

## Setup

- BPE-512, 990,811 train / 1,169,238 test, окно 256 (4×64+реле).
- Hierarchical chaotic mixer: 1 проход (8 локальных + 4 глобальных блоков).
- V1: readout = h_last + gmean → MLP → logits. Никакого attention.
- V2: 1 проход → запомнить запрос → 2 раунда: (восстановить запрос + смешать).
  Readout: h_last + gmean → MLP. Никакого attention.
- β-приор: order-2, β=0.3.
- 6000 шагов, batch 64, lr 1e-3.

## Results (20,000 тестовых позиций)

| Модель | PPL | PPL+β | top-1+β | loss @6K |
|---|---|---|---|---|
| **V1 (local readout, no attn)** | **32.83** | **13.79** | **40.68%** | 3.96 |
| V2 (query-anchor) | 45.34 | 15.27 | 40.66% | 3.76 |
| L1+attn-readout (exp14) | 32.47 | 13.74 | 40.56% | 3.96 |

## Interpretation

1. **V1 даёт ту же точность, что и attention-readout**: разница 0.36 PPL
   модели и 0.05 PPL с β — в пределах шума. **Attention-readout можно убрать
   без потери качества.** Вся модель становится attention-free:
   - Смешивание: O(W log W) (карта Арнольда + сцепление)
   - Readout: O(d) (локальный MLP)
   - Приор: O(1) (таблица n-грамм)
   - **Итого: O(W log W) — ни одного QKV-матмула, ни одного softmax.**

2. **V2 (якорь) проигрывает V1** (PPL 45.3 vs 32.8). Причина: перезапись
   состояния запроса (h[:, -1, :] = anchor) разрушает накопленные контекстные
   представления. Динамика «вокруг якоря» не улучшает селекцию — она теряет
   информацию.

3. **Почему V1 работает**: динамика — широковещательный канал (broadcast),
   не маршрутизатор. После T шагов смешивания каждый токен содержит сжатую
   информацию о всём контексте. Readout (MLP) + β-приор — достаточная
   селекция. Dot-product attention даёт более точную контентную селекцию,
   но на этом домене (BPE-код, β-приор) выигрыш минимален (< 0.5 PPL).

## Theoretical conclusion

**Можно ли заменить attention-readout селектором из динамики пространства?**

**Да — и это уже сделано в V1.** Динамика доставляет информацию;
локальный MLP + β-приор селектируют. Никакого attention в модели нет.

**Что НЕ работает:** принудительное «впрыскивание» запроса обратно в динамику
(якорь). Математическая причина: фиксированная обратимая динамика —
контент-независимая пермутация; она не может «выбрать» на основе содержания.
Контент входит только через начальное состояние и readout. Якорь — попытка
впрыснуть контент в середину динамики, но это разрушает состояние.

**Что остаётся:** контент-зависимое сцепление (coupling, зависящий от
содержимого токенов) — это был бы полноценный селектор из динамики, но
без дополнительной структуры это O(N²) — возврат к attention.

## Conclusion

**Подтверждено**: attention-readout можно убрать. Архитектура v0.3 —
полностью attention-free: хаотический миксер + локальный readout + β-приор.
Точность та же, стоимость O(W log W).
