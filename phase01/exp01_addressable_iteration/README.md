# Experiment 01 — Addressable Iteration (random access in time)

## Hypothesis

Можно ли вычислить x_t = A^t·x₀ напрямую, без последовательных итераций? Это фундамент идеи «хаос как адресуемое вычислительное пространство».

## Mathematical model

A = [[1,1],[1,2]] имеет **замкнутую форму**: Aᵗ = [[F₂ₜ₋₁, F₂ₜ],[F₂ₜ, F₂ₜ₊₁]] (числа Фибоначчи). x_t вычисляется за O(log t) (fast doubling) или ~O(1) для 2×2.

## Setup

t = 10 … 10¹⁸, N = 1000. Сравнение: замкнутая форма vs бинарное возведение vs последовательные итерации.

## Results

| t | closed (s) | fastpow (s) | sequential (s) | speedup vs seq |
|---|---|---|---|---|
| 1000 | 2.1e-5 | 5.4e-5 | 2.4e-3 | 1.1e2 |
| 10⁶ | 3.2e-5 | 8.4e-5 | 3.4 | 1.1e5 |
| 10⁹ | 4.2e-5 | 1.2e-4 | 3.2e3 | 7.7e7 |
| 10¹⁸ | 7.0e-5 | 2.6e-4 | 3.4e12 | 4.8e16 |

- **Точность**: замкнутая форма == быстрое возведение == последовательно (все t).
- **Вычислимость**: XOR (parity) линейно представим из x_t mod 2; **AND — НЕТ** (линейная карта не может вычислить нелинейную функцию).

## Interpretation

1. **Адресность есть**: любое состояние траектории доступно за O(log t) — даже O(1)-константа для 2×2. Проверено до t = 10¹⁸.
2. **НО** честный baseline для линейной карты — матричная степень O(log t), а НЕ последовательная итерация O(t). Сравнение «O(log t) vs O(t)» — против соломенного чучела. Хаотическая замкнутая форма **равна** честному baseline, не лучше.
3. **Цена адресности — линейность**: адресуемость существует именно потому, что карта линейна (Aᵗ = матрица Фибоначчи). Линейная карта не выражает AND — глубины «через итерации» нет: Aᵗ·x₀ это ОДНА линейная функция x₀.

## Conclusion

**Подтверждено (адресность), но как тривиальное свойство линейных карт.** Оно не даёт преимущества над честным baseline (O(log t) == O(log t)) и не даёт вычислительной мощности (нелинейные функции невыразимы).
