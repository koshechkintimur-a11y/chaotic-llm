# Experiment 02 — Chaotic Router / Address Space

## Hypothesis

Может ли начальное состояние x₀ кодировать маршрут к целевой области (эксперту) в хаотическом пространстве, дешевле baseline-роутера (hash / MoE / scan)?

## Mathematical model

Орбита x₀ под действием A — цикл длины ≤ T(N). Период T(N) ≈ 0.75N (степени двойки). Доля пространства, покрываемая одной орбитой: ≤ T(N)/N² ≈ 0.75/N.

## Results

### Структура орбит
| N | T(N) | длина орбиты (среднее) | доля пространства |
|---|---|---|---|
| 32 | 24 | 20.6 | 2.0% |
| 64 | 48 | 39.7 | 1.0% |
| 128 | 96 | 82.1 | 0.5% |
| 256 | 192 | 158.3 | 0.24% |

### Досягаемость цели (N=128)
| Цель | Досягаемость из случайного x₀ |
|---|---|
| случайная клетка | **0.45%** |
| шар r=1 (9 кл.) | 4.2% |
| шар r=3 (49 кл.) | 25% |
| шар r=5 (121 кл.) | 47% |
| шар r=8 (289 кл., 1.8% простр.) | 77% |

## Interpretation

1. **Траекторное пространство одной орбиты — O(N) клеток, не O(N²).** Для N=128 орбита покрывает 0.5% пространства. С ростом N доля падает как 1/N.
2. **Из случайного x₀ цель недостижима в 99.5% случаев** (для точечной цели). Чтобы роутер работал, области должны быть огромными (1.8% пространства на эксперта при 77% досягаемости) — это уже не «области-эксперты», а большие перекрывающиеся шары.
3. **Адресный прыжок не решает задачу поиска**: «прыгнуть на шаг t» стоит O(log t), но «найти t, при котором орбита попадает в R» — это ПОИСК по орбите (O(длины) скан или O(длины) индекс). Адресность убирает только стоимость итерации, не стоимость поиска.
4. **Поглощаемость в нейросети**: фиксированная линейная карта между обученными слоями поглощаема — c(Aᵀ·e(context)) ≡ c′(e(context)), классификатор той же ёмкости. Карта не добавляет ни ёмкости, ни маршрутной силы.

## Conclusion

**Опровергнуто (маршрутизация)**: хаотический роутер ограничен крошечным траекторным пространством (0.75/N пространства), требует поиска для нахождения нужного шага и в нейросети поглощаем. Он строго хуже hash-таблицы.
