# Experiment 04 + 05 — Error/Correction and Chaotic Locality

## exp04 — Local error and recovery

## Hypothesis

Чувствительна ли система к ошибке состояния, и существует ли дешёвый механизм коррекции?

## Results

Два состояния x, x+ε=(1,0), N=256:
- **Позиционное пространство**: расстояние между траекториями растёт (Lyapunov ≈ 2.6) и флуктуирует (std 64–71, max ~300) до насыщения тором. Хаос в позициях — реален.
- **Пространство значений** (то, что архитектура реально пермутирует): вектор состояния — перестановка своих элементов, его L2-норма сохраняется точно. Ошибки значений НЕ расходятся.

## Interpretation

- Автономная обратимая карта: ошибки значений не растут; замкнутая форма (exp01) даёт x_t точно — дрейфа нет, коррекция не нужна (C_correction = 0).
- «Ожидаемой траектории», к которой можно корректировать, не существует: динамика детерминирована. Коррекция имеет смысл только для управляемых динамик — а там она стоит O(T) последовательной симуляции, как у любого RNN.

## Conclusion

**Коррекция не даёт преимущества**: для автономной карты она не нужна, для управляемой — равна стоимости RNN.

## exp05 — Chaotic locality

## Hypothesis

Существуют ли «семантические окрестности»: похожие входы → похожие маршруты?

## Results

corr(d₀, d_t) при t = 1,2,3,5,8,12,20: +0.039, −0.018, −0.031, −0.006, −0.022, +0.070, +0.013.

## Interpretation

Корреляция между начальным расстоянием и расстоянием траекторий ≈ 0 уже через 1–2 шага (перемешивание). Похожие входы НЕ имеют похожих маршрутов — семантическая локальность в карте Арнольда отсутствует.

## Conclusion

**Опровергнуто (локальность)**: семантические окрестности не существуют; архитектура теряет один из предполагаемых плюсов.
