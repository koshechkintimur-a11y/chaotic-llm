# Experiment 09 — Reversibility Under Control

## Hypothesis

Если X_{t+1} = F(X_t, θ_t) с динамическим управлением θ_t, сохраняется ли Decode(Encode(X)) = X?

## Setup

ChaoticMixer (4 блока, d=8) на задаче A. Decode: инверсия каждого блока (обратная перестановка + обратное сцепление), блоки в обратном порядке.

## Results

| Конфигурация | Max decode error |
|---|---|
| Без GSF (фиксированный гейт) | **4.7e-6** ✓ |
| С GSF, гейты СОХРАНЕНЫ | **1.2e-6** ✓ |
| С GSF, гейты ПЕРЕСЧИТАНЫ на обратном ходе | **0.36** ✗ |

## Interpretation

- Без управления динамика обратима в точности (ошибка ~1e-6, машинная точность).
- С GSF обратимость сохраняется ТОЛЬКО если хранить управляющие сигналы (гейты), потому что гейты зависят от состояния x_t, которое на обратном ходе неизвестно.
- Если пересчитывать гейты из «испорченного» состояния — ошибка 0.36 (полная потеря обратимости).
- Аналогично, adaptive depth требует знать, на каком шаге остановились (T).

## Conclusion

**Ограничение зафиксировано (как предписывал протокол)**: вход-зависимое управление разрушает обратимость, если не кэшировать управляющие сигналы. Это делает «обратимый хаотический transformer с GSF» необратимым в строгом смысле (нужна память на гейты размера N·d·T).
