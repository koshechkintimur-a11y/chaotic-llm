# Experiment 00 — Reversibility

## Hypothesis

Карта Арнольда (det=1) является биекцией на Z\_N². Должно выполняться F⁻¹(F(X)) = X для всех N и всех состояний с точностью до машинной.

## Mathematical model

$$
F(x,y) = (x+y,\; x+2y) \bmod N
\qquad
F^{-1}(x,y) = (2x-y,\; -x+y) \bmod N
$$

## Setup

- N = {8, 16, 32, 64, 128, 256, 512, 1024}
- Случайные состояния: 2000 точек на Z\_N²
- t = {1, 2, 3, 7, 11} итераций
- Измерены: максимальная ошибка инверсии, доля точных восстановлений, периоды орбит состояний, период карты T(N)

## Baseline

Теоретический предел: ошибка = 0 (биекция)

## Results

- **Максимальная ошибка инверсии**: 0 (все N, все t) ✓
- **Доля точных восстановлений**: 1.0 (все N, все t) ✓
- **Обратимость на последовательностях токенов (квадратный grid)**: 1.0 ✓
- **Период T(N)**: T(2^k) = 3·2^{k-2} (k≥3), T(8)=6, T(16)=12, T(32)=24, …
- **Орбиты состояний**: максимальный период = T(N) (на выборке)

## Interpretation

- Карта Арнольда обратима в точности на Z\_N² (математический факт, подтверждён).
- Обратимость на последовательности токенов требует точного квадрата (n_tokens = N²); иначе отображение на подмножестве не является перестановкой — важное ограничение для архитектуры.

## Failure modes

- Для не-квадратных чисел токенов (n_tokens ≠ N²) отображение не является перестановкой на токенах — часть токенов «выпадает» за пределы поля. Требуется паддинг до ближайшего квадрата.

## Conclusion

**Подтверждено**: карта Арнольда обратима точно.
