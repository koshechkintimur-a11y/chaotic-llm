# Experiment 07 — Adaptive Depth

## Hypothesis

Система может сама решать, когда остановиться (T(q) вместо фиксированного T). Снижает ли это среднюю стоимость inference (Q4, уровень 4)?

## Setup

ChaoticMixer (8 блоков) обучен на задаче A (associative recall, N=16). На inference обрезаем forward до первых T блоков, T = 1..8.

## Results

| T (глубина) | Accuracy |
|---|---|
| 1 | 0.108 |
| 2 | 0.123 |
| 3 | 0.154 |
| 4 | 0.171 |
| 5 | 0.184 |
| 6 | 0.191 |
| 7 | 0.176 |
| 8 | 0.205 |

## Interpretation

- Точность растёт с глубиной (0.11 → 0.21), но **прирост затухает**: большинство сигнала дают первые 2–4 блока.
- Кривая accuracy(T) монотонна нестрого; шум на T=7.
- Потенциальный выигрыш adaptive depth: если останавливаться на T=4, экономия ~50% compute при потере ~0.03 accuracy. НО для этого нужен рабочий критерий остановки (см. exp_08 — наивный критерий не сработал).

## Conclusion

**Частично подтверждено**: точность насыщается до конца глубины, так что адаптивная глубина теоретически экономит compute. Практический критерий остановки не найден (exp_08).
