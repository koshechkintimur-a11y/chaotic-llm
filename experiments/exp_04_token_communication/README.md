# Experiment 04 — Token Communication

## Hypothesis

Может ли информация от одного токена достигать других через хаотическую динамику, и что для этого нужно (Phase 1: токены A B C D [KEY] E F G H)?

## Setup

N=256 токенов, сигнал в токене 0, поддержка (число ненулевых токенов) после t шагов. Расписания: Arnold (одна и та же карта каждый шаг), random, fixed, shift. Сцепления: только перестановка; перестановка + симметричное парное сцепление.

## Results (детали — exp_03)

| Расписание | Чистая перестановка | + симметричное сцепление |
|---|---|---|
| Arnold | поддержка = 1/N (без распространения) | 100% за log₂(N)+2 шага |
| random/fixed | 1/N | 100% за log₂(N)+2 шага |
| shift | 1/N | линейный рост, <100% |

Обученная селективность (задача A, N=16): Chaotic+MLP-readout = 0.20, Chaotic+attention-readout = 0.92 (см. exp_10/12).

## Interpretation

1. **Перестановка сама по себе не коммуницирует** — это биекция, поддержка сохраняется (математический факт). Нужно сцепление.
2. **Сцепление + перестановка даёт O(log N) распространение** — каждый токен может получить информацию от любого другого за log₂(N)+2 шага.
3. **Но распространение ≠ выбор**: чтобы токен-запрос ИЗВЛЁК нужную информацию из смеси, нужен контент-зависимый readout (0.92 против 0.20).

## Conclusion

**Подтверждено (уровень 1 частично)**: хаотическое перемешивание эффективно распространяет информацию между токенами (O(log N) шагов). НО это свойство класса «перестановка + сцепление», а не специфики карты Арнольда (random/fixed дают тот же результат).
