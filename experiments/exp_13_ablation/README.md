# Experiment 13 — Ablation Study

## Hypothesis

Какой компонент ChaoticMixer действительно нужен? Удаляем по одному и измеряем Accuracy на задаче A (N=16).

## Setup

Все варианты: d=32, 400 эпох, задача A.

## Results

| Вариант | Accuracy | Что убрано |
|---|---|---|
| full_gsf | 0.189 | — (полная система) |
| no_gsf | 0.190 | GSF (гейты) |
| shallow_3 | 0.173 | глубина 6 → 3 |
| deep_10 | 0.184 | глубина 6 → 10 |
| **perm_only** | **0.068** | сцепление (только перестановка) |
| no_perm | 0.180 | перестановка (только сцепление) |

## Interpretation

1. **perm_only → шанс (0.068)**: перестановка без смешивания значений не даёт НИЧЕГО. Подтверждает математический факт exp_02: биекция не перемешивает значения. Сцепление — обязательный компонент.
2. **no_perm → 0.180**: сцепление без перестановки почти так же «хорошо», как полная система (0.19). Но это ЛОКАЛЬНЫЙ эффект: без перестановки query связан только со своей парой (позиции 14–15), и 0.18 ≈ доля случаев, когда ответ случайно в этой паре. Не настоящая коммуникация.
3. **GSF → 0**: удаление GSF ничего не меняет (0.189 vs 0.190). GSF-гейт НЕ является необходимой частью архитектуры в текущей формулировке (критерий §23: «если убрать и ничего не меняется — не нужен»).
4. **Глубина**: 3–10 блоков почти не влияет (0.17–0.18) — для N=16 mixing насыщается быстро; узкое место не глубина, а селективность readout.

## Conclusion

- Сцепление ОБЯЗАТЕЛЬНО (без него шанс).
- Перестановка даёт маршрутизацию, но её вклад в задаче A мал на фоне отсутствия селективности.
- GSF-гейты — необязательный компонент (0 эффекта).
