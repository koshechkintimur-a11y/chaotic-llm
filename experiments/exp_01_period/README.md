# Experiment 01 — Period

## Hypothesis

Период T(N) карты Арнольда — минимальное t > 0 такое, что Aᵗ ≡ I (mod N). T(N) немонотонен и флуктуирует.

## Mathematical model

$$
T(N) = \min\{t > 0 : A^t = I \bmod N\},\qquad
A = \begin{pmatrix}1&1\\1&2\end{pmatrix}
$$

## Setup

- N = 2..1024
- Вычисление: итерация A ← A·A mod N до возврата к I

## Baseline

Известные значения: T(2)=3, T(3)=4, T(2^k)=3·2^{k-2} (k≥3). Проверка: T(8)=6, T(16)=12, T(32)=24.

## Results

- **Макс. T(N)**: 1500 при N=750
- **Среднее T(N)**: 230.1
- **Среднее T(N)/N**: 0.51
- **Макс. T(N)/N**: 3.0
- **Контрольные точки**: все верны (T(8)=6, T(16)=12, T(32)=24, T(3)=4)

## Interpretation

- T(N) растёт ~0.5N в среднем, с выбросами до 3N.
- Для степеней двойки T(N) = 3·2^{k-2} (линейный по N).
- Период немонотонен: N=750 даёт пик 1500, соседние N могут иметь T < 100.
- **Практическое следствие**: для архитектуры с T шагов, T ~ log N достаточно для распространения информации (см. exp_03), что много меньше T(N) — так что цикличность карты не проблема на коротких траекториях.

## Failure modes

- Вычисление period(N) итеративно — при N > 2000 становится медленным (O(N³) шагов в худшем случае). Для N ≤ 1024 приемлемо.

## Conclusion

**Подтверждено**: период T(N) флуктуирует, среднее ~0.5N, макс. ~3N.
