# Experiment 06 — GSF (Global State Field)

## Hypothesis

Может ли малый управляющий сигнал направлять хаотическую динамику (Q2, Q3)? Два подвопроса: (a) комбинаторный — можно ли «вести» траекторию к цели управляющим сигналом; (b) обученный — даёт ли GSF селективность.

## exp_06a — steering (комбинаторный)

Динамика: x_{t+1} = A·x_t + c_t (mod N) на решётке N×N. Цель — попасть в заданную клетку. Управление c_t:
- **greedy** (знает цель): c_t = (target − A·x_t) mod N
- **random**: c_t случайно
- **zero**: c_t = 0

Результат (все N от 32 до 1024):

| Управление | Success rate |
|---|---|
| greedy (знает цель) | **1.00** |
| random | ~0.00–0.06 |
| zero | 0.00 |

**Интерпретация**: управлять хаосом можно, но только если управляющий сигнал КОДИРУЕТ цель. Случайный/нулевой контроль не попадает в цель никогда. Это информация-теоретический предел: чтобы выбрать 1 цель из N, управление должно нести ≥ log₂(N) бит. «Маленький сигнал ведёт большое пространство» — правда только при условии, что сигнал знает, куда вести.

## exp_06b — GSF как гейт (обученный)

В ChaoticMixer GSF = MLP над (состояние + пул), выдающий per-token гейты сцепления. Результаты (задача A, N=16):

| Модель | Accuracy |
|---|---|
| Chaotic+GSF | 0.194–0.29 (зависит от позиции запроса) |
| Chaotic (без GSF) | 0.200 |
| Chaotic+AttentionReadout | **0.915** |

**Вывод**: GSF-гейт НЕ даёт селективности — модуляция силы смешивания сама по себе не позволяет выбрать нужный токен. Селективность обеспечивает контент-зависимый readout (0.915). Задача D (retrieval по цепочке) Chaotic+GSF решает идеально (1.0) — там GSF помогает, но это частный случай.

## Cost of GSF

GSF с пулом по всем токенам стоит O(N·d) (пул) + MLP. Это не «бесплатно»: на каждом блоке добавка O(N·d).

## Conclusion

**Частично подтверждено**: GSF может модулировать динамику, но селективность (Q2) требует контент-зависимого выбора, который GSF-гейт не обеспечивает. Маленький сигнал направляет пространство только если он кодирует цель (exp_06a).
