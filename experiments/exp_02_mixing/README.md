# Experiment 02 — Chaos vs Mixing

## Hypothesis

Проверяем, как расстояние между двумя близкими состояниями эволюционирует под действием разных динамик.

## Key Finding

**Любая перестановка (включая карту Арнольда) сохраняет L2-расстояние между векторами состояния.** Перестановки — изометрии; они не перемешивают значения. Смешивание требует операции сцепления (coupling).

## Mathematical model

$$
d_t = \|F^t(X) - F^t(X+\varepsilon)\|_2
$$

Сравниваем: Arnold map, fixed permutation, random permutation (та же на оба состояния), translation, Arnold + coupling.

## Setup

- N=256 токенов (16×16 grid)
- X: 1.0 в токене 0; X+ε: 1.0 в токене 0, +0.01 в токене 5
- T=60 шагов (одинаковая карта на каждом шаге для каждого расписания)
- Coupling: X_dst += 0.5·X_src (чередование половин)

## Results

| Динамика | d_t (среднее) | Характер |
|---|---|---|
| Arnold (perm) | 0.01 | Константа |
| Fixed perm | 0.01 | Константа |
| Random perm (та же) | 0.01 | Константа |
| Translation | 0.01 | Константа |
| Arnold + coupling | 224 → 2686 (60 steps) | Экспоненциальный рост |

**Рост значений при additive coupling**: 1.0 → 1.5·10²⁰ за 200 шагов. Коэффициент 0.5 даёт умножение на ~1.5 за шаг, т.е. 1.5^t. **Наивное аддитивное сцепление численно нестабильно.**

## Interpretation

1. Перестановки (все) — изометрии: d_t = const. Перемешивание значений требует combine (coupling).
2. Coupling с 0.5·src → dst создаёт экспоненциальный рост значений (1.5^t). Для практической архитектуры нужно bounded coupling (tanh, нормализация).
3. Фиксированная точка (0,0): токен на позиции (0,0) никогда не двигается — дефект карты.

## Conclusion

**Подтверждено**: перестановки не смешивают значения. **Подтверждено**: additive coupling нестабилен (нужен bounded). **Подтверждено**: (0,0) — фиксированная точка.
